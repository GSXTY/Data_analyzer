# 呼吸波形查看器

面向小范围研发试用的本地 Windows 波形分析工具。CSV 和标记数据保留在使用者电脑；无需公司服务器、Codex 或云端模型即可查看、自动筛查和人工标记。

## 下载与启动

在 [Releases](https://github.com/GSXTY/Data_analyzer/releases) 下载 `RespiratoryViewer-版本-windows-x64.zip`，解压整个文件夹后双击 `RespiratoryViewer.exe`。浏览器会打开本机网页 `http://127.0.0.1:8765`。保持运行窗口打开；关闭窗口或 Ctrl+C 退出。新版发布后从同一页面下载，关闭旧版再运行新版。

main分支源码包含当前算法和界面更新；源码同步不会自动更新已下载的EXE，Windows试用包以Releases页面对应版本为准。

Windows 试用包未做代码签名。具体操作见 [使用说明](USER_GUIDE.md)。本仓库未设置公开开源许可证；依赖仍按各自许可证分发。

## 使用流程

1. 打开CSV。默认按旧脚本估算展开重复时间戳、气压1/2减气压3，并叠加压力通道。支持通道搜索、分图/叠加、横向拖动、Ctrl+滚轮缩放和时间定位。

可用“添加CSV（可多选）”建立本次会话的文件列表，在左侧搜索、点击切换；各文件独立保存标记与查看位置。只解析当前文件，不做跨文件叠加。刷新后重新选择文件可恢复标记和查看设置；多个浏览器标签页仍共享服务的当前文件。
2. 检测方案仅保留“幅度规则（试验）”和“动态基线优化v3”（默认）。v3支持1～10秒检测窗口、5～10秒最短持续，默认5/10；幅度规则使用5秒极差和所设连续持续门限。选择检测类型后扫描整份文件或当前区间；完成后仅显示本次批次的候选，旧记录可从历史批次查看。
3. 正确候选点“确认”，误报点“忽略”；类型/边界可修改；漏检可手动框选补充。忽略保留记录，避免重复扫描后重新出现。
4. 选择扫描批次，填写校验人、检查范围、实际检查的类型及逐条/完整检查方式，点击“一键保存反馈文件夹”。预览后由使用者勾选确认才保存。校验JSON仅含所选范围/类型的标记，跨边界和估算时间标记单列，不直接用于训练；其余数据保持未知。
5. 文件夹包含一份原始CSV、每批自动JSON、按内容保存的人工JSON及配对清单；相同内容再次保存会复用。首次通过公司指定渠道交回整个文件夹，之后补交新增文件即可，已持有的相同CSV无需重复传送。新扫描批次对应的自动JSON需一并补交。
6. 负责人打开对应原始CSV，使用“查看收回的校验JSON”只读比较并跳转波形，不覆盖本机标记。人工校验不会自动训练程序，需要研发人员修改算法后验证。

## 数据与更新

打包版存储在 `%LOCALAPPDATA%\VVFLY\RespiratoryViewer\events.sqlite3`，与解压目录分离。升级程序不会覆盖标记。开发运行默认存储在项目 `data/`；可用 `--data-dir` 指定目录。旧浏览器标记首次打开时合并，冲突会提示。建议导出JSON备份。

常用列表默认最近10次未归档批次，历史窗口支持搜索、每页20条、重命名和归档恢复。网页遇到同条件已有批次会提示复用或重新扫描；重新扫描才新建快照。归档不删除快照或人工标记。

人工变更历史仍保存在事件库；新版version=2校验JSON只保存声明范围/类型及训练有效性说明，不反复嵌入整份历史和自动快照。仍有相关待复核等问题时不能声明完整检查。训练导入与模型训练尚未实现，未来需按文件指纹、标注ID及覆盖范围合并版本、裁定冲突。反馈不自动上传GitHub；CSV、反馈、数据库及依赖/构建目录不纳入Git。

## 检测含义

新增独立“多特征自适应测试（新版）”：保留旧v2可选，使用CSV机器总流量，5秒鲁棒幅度、前120秒参考、默认持续≥7秒。近消失严格剩余≤10%，减弱默认剩余≤50%，取消绝对3 L/min下限；迟滞只保留过程上下文，不把超门限秒数计入严格达标区间。噪声代理未标定，压力/总漏气、平直/尖峰等为复核依据。点击“显示输入与A”可查看A、B、实际门限及百分比，参数与扫描一致。不是厂商完整算法复现，不改变治疗设置。详见[多特征测试说明](docs/MULTIFEATURE_TEST_ALGORITHM.md)。

离线动态基线对照：`python dynamic_baseline_comparison.py "文件.csv"` 在 `data/reports/dynamic-baseline/文件指纹前12位/` 生成报告、完整候选JSON和曲线数据。比较2/5/8秒的总流量绝对值均值及窗口去均值RMS，采用前100秒参考和10秒持续条件评估窗口影响；不减总漏气、不重建Patient Flow、不写入网页事件，也不替换现有7秒方案。去均值RMS仅描述机器波动，重复源时间戳下未实现可验证的1Hz滤波。候选数量不代表准确率；先确认流量公式、漏气/面罩排气组成及采样时钟，再评估正式患者流量方案。

正式保存试验候选：上方检测方案选择“动态基线检测（试验）”，选择一种方法和一个2秒/5秒/8秒窗口，勾选类型后“扫描整份文件”或“扫描当前区间”。此方案固定连续10秒，不能沿用其他方案的7秒；结果进入独立“动态基线检测”页签，支持跳转、确认、修改、忽略、JSON备份及反馈包。默认按上方方法/窗口筛选；“查看所有方法/窗口”仅用于对照，重叠结果不能相加计数。自动快照保留原始判定，人工修改保留原方法、窗口和证据；重复扫描不会覆盖人工结果。详见 [动态基线检测说明](docs/DYNAMIC_BASELINE_DETECTION.md)。MCP `analyze_recording`（只读）和 `detect_events`（保存候选）均支持 `profile=dynamic_baseline,dynamic_method=centered_rms|absolute_mean,window_seconds=2|5|8`，默认去均值RMS/2秒。输入仍为未经患者流量验证的机器总流量，不代表临床事件或ResMed原版算法。

所有算法统一从“检测方案”下拉框进入，不再提供单独的动态基线只读对照面板。选择动态基线的方法和2/5/8秒窗口，点击“显示强度与基线”查看当前配置曲线，点击扫描保存候选；切换方法或窗口分别比较。左侧默认列出常用通道和当前算法相关通道；“显示全部通道”或搜索可找其他字段，已主动选择的通道继续可见。切换方案收起上一方案的派生曲线，旧版全通道查看偏好自动收敛为相关通道；原CSV和事件标注不变。后台只读分析与离线对照继续用于研发验证，Agent使用统一profile分析或检测。后续新算法也统一注册到此下拉框及现有扫描/复核/导出流程。

新增“动态基线优化测试（新版v2）”：独立 `dynamic_baseline_v2`，默认去背景绝对值法＋5秒主窗。因果30秒稳健背景、100秒参考，预候选冻结；无事件且质量有效的短暂下降按原时间回填。3秒预触发只用于生成候选，最终1秒复核分箱严格连续≥10秒且有主窗口减弱佐证；估计波形区间、主窗口达标区间与确认时刻分别保存，不按W固定前移。≥120秒长段保留并提示复核，≤10%只作强度标记。新旧结果/方法/窗口分开，保存、人工修改、导出与MCP均接入统一流程。详见 [优化测试v2说明](docs/DYNAMIC_BASELINE_OPTIMIZED_V2.md)；该版本未证明临床准确率。

新增独立“自适应测试算法”：CSV流量的5秒鲁棒幅度、事件期间冻结参考、迟滞防拆段；近消失核心区与整体减弱过程分开记录。图中提供对应测试A，结果在独立页签，保留原有规则。属于未验收的研发候选，详见[测试算法说明](docs/ADAPTIVE_TEST_ALGORITHM.md)。

新增“公司规则（试验）”：使用气压1/2分别减气压3后的多项式推算Q，暂按L/min；5秒Q最大值−最小值每秒更新，A<10或10<A<17连续超过默认7秒生成公司候选，等号暂不归类。窗口/计时与单位口径仍待研发确认，不执行调压。它与70%相对幅度方案独立；参数及公式版本随批次导出。重启查看器并重新导入CSV后可选择“公司公式Q（试验）”通道。详见[试验口径](docs/COMPANY_RULES_TRIAL.md)。

输入是**机器总流量和总漏气**，不相减、不重建患者流量。规则读取全部原始样本，按源时间戳分秒统计流量5%～95%分位差，取3秒最大值作为波动包络，与前120秒75分位参考比较。前30秒/中断/状态变化后基线不足、有效样本不足的区间不产生流量减弱候选；压力设置突变与总漏气升高作为干扰排除。

瞬时总漏气率相对基线超过 `max(10 L/min, 基线绝对值×50%, 4×偏差MAD)` 并持续达到阈值，标为总漏气升高；时间中断与采样不足生成质量事件。

这是未经临床验证的工程筛查，不是确诊暂停/低通气，不区分中枢/阻塞、不计算AHI。当前设备压力单位Pa、机器总流量和瞬时总漏气率L/min已确认；通道更新频率与采样时序仍待核实。原始计时为秒级，旧脚本秒内时间是估算。显示模式不改写标记计时依据。旧脚本模式沿用第14列大于125减256（已知压力字段除外）及121秒断线规则，原始模式超过1秒断线。

## 开发与打包

Python 3.12，Windows x64：

```powershell
python -m pip install -r requirements.txt
python viewer.py
python viewer.py "C:\path\recording.csv"
python -m unittest discover -s tests -v
node tests/test_annotations.cjs
node tests/test_interaction.cjs
node tests/test_event_filters.cjs
python -m pip install -r requirements-build.txt
python build_windows.py
python tests/package_smoke.py dist/RespiratoryViewer/RespiratoryViewer.exe
```

打包输出到 `release/`，包含ZIP和SHA-256。构建显式包含程序与网页资源，不打包CSV/数据库。GitHub Actions 手动运行生成下载制品；推送与 `app_version.py` 匹配的 `v版本` 标签时构建并发布预发布版。

主文件：`viewer.py` 本机服务；`detector.py` 检测；`event_store.py` 标记/历史/快照；`viewer.js` 网页交互；`annotation-model.js` 标记校验和反馈比较。

## 可选 Skill 与 MCP

`skills/respiratory-waveform` 是配套Skill；`respiratory_mcp.py` 使用官方 MCP Python SDK，以stdio连接本机查看器。可选安装 `requirements-mcp.txt`，配置示例见 `mcp-config.example.json`。查看器未启动时MCP无法工作。

支持读取当前文件与显示波形、事件列表、创建/修改Agent候选、统计、`detect_events` 自动筛查和 `analyze_recording` 只读证据分析。后者使用完整原始数据返回候选时段、持续时间、压力/总漏气变化和参考窗口影响，不保存批次、不修改人工标签。代表事件默认10条、最多50条，并非整个事件列表；总数统计对应所选完整区间。先分析，再按用户要求保存候选，人工确认仍在网页完成。识别采用现有设备规则及证据复核提示，尚未接入训练分类模型。

升级后重启查看器，并重新连接MCP（必要时重启使用Agent的客户端）才能加载新工具。源码中的Skill需同步到Agent使用的技能目录；本仓库的 `skills/respiratory-waveform/SKILL.md` 与MCP可在支持相应协议的其他Agent中复用。网页与MCP共用本机事件库，候选需人工确认。显示抽取点不能代替完整采样检测。MCP仅访问当前文件，不提供任意Python执行。隔离测试：`python tests/mcp_smoke.py`。

新增“动态基线优化测试（v3 · 漏气提示 / 弱事件改进）”：漏气变化保留强度参考并提示复核；持续减弱改用主窗口剩余<50%连续10秒，不再要求每个1秒复核值都达标。显著下降保留1秒复核规则。弱事件按窗口末端计时，v2可继续对照。详见 [优化测试v3说明](docs/DYNAMIC_BASELINE_OPTIMIZED_V3.md)。

v3现支持1～10秒检测窗口和5～10秒最短持续（整数选择，默认5/10）。每次扫描或复用批次后，列表和色带仅显示该批次，0条时不显示旧候选；历史通过“显示所选批次”查看。参数与原始自动证据保留在JSON和反馈包中。

日常检测入口现仅保留“幅度规则（试验）”和“动态基线优化v3”，默认v3；其他方案停止在网页提供扫描，旧批次和人工标注可通过历史继续查看、复核及导出。幅度规则点击扫描后自动保存达标区间为待复核候选；显示输入与A只绘图。默认5秒极差A，A<10或10<A<17需连续超过所设持续门限（默认7秒），A=10/17不归类。
