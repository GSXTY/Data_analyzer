# 自适应测试算法

独立检测方案：网页选择“自适应测试算法”，当前版本adaptive-flow-test-v2-causal，默认CSV机器总流量、连续最短7秒、减弱进入比例50%。原有自动检测和固定幅度规则保留。

## 幅度与参考

每个源时间秒至少5个有限流量值，取2%和98%分位。取最近5个完整有效源秒的高分位最大值减低分位最小值，作为测试幅度A。因果计算不读取未来样本；界面“测试幅度A（5秒鲁棒）”与检测共用该计算。缺口、秒内混合状态、运行状态/模式变化、治疗压突变会重置窗口和参考。每秒记录行数不代表独立采样率。

参考为前120秒内至少30个有效、非候选过程的幅度75分位，幅度至少12 L/min；候选期间冻结。参考不足时不判事件，未命中不等于已确认正常。

减弱进入门限=max(参考×所选比例,3 L/min)，退出门限=max(参考×min(95%,max(比例+5%,min(75%,比例×1.2))),3.9 L/min)。近消失进入=max(参考×10%,3 L/min)，退出为进入的1.3倍。3 L/min是待验证工程下限，不代表临床阈值。迟滞保持区计入状态持续时间，备注记录实际数值。

## 分段与边界

先跟踪完整减弱过程。若其中存在持续达到最短门限的近消失核心区，分别生成核心区候选，整体减弱过程供上下文复核；不将恢复肩部标成近消失。短暂近消失未达持续要求时，不拆开整段减弱候选。

事件区间是首次进入至首次退出/截断的半开区间，按窗口末端计时；不自动前后扩展。备注中的“波形参考”只向前展示5秒上下文，不是已验证真实起点，也不加入事件时长。它与旧固定规则的首次/末次满足点跨度口径不同，可能出现1秒等差异。

分析参考完整记录，返回与选择区间相交的完整事件；跨区间事件注明边界，后续人工校验仍应单列跨检查范围事件。记录尾部、缺口或设置变化造成的终点截断会提示复核。来源、参数、版本、判定证据随批次保存。修改选择类型不改变同一事件ID；相同设置重扫精确去重，不覆盖已复核/忽略记录。不同参数实验独立保存，比较时按批次，勿直接累加重叠候选。

压力/治疗压中位变化≥20Pa、总漏气中位变化≥10 L/min为复核提示，不是病因或临床分类。机器总流量不减总漏气，不输出OA/CA、临床低通气、正常或AHI。

## 使用与验证

刷新后选择新方案，点击“显示输入与A”，然后扫描。测试结果在“自适应测试”页签独立查看、确认、忽略和导出。MCP使用profile=adaptive_test，默认减弱比例50%、持续7秒；可先只读分析再按要求保存候选。需要重连MCP加载新增参数。

使用三份已有CSV做了只读回放，并使用合成信号测试因果性、参考冻结、短暂跨阈值不拆段、区间边界、重复ID和选区身份稳定性。算法未用人工完整标注集验收，不能声称检出率或准确率提高。下一步固定参数、按独立记录和人工检查覆盖范围比较误报、漏检、边界误差及可分析覆盖率。

## 7秒版本的计时约定

首次达标窗口末端开始计时，达到7秒即可生成候选；6秒不生成。恢复评价时刻作为半开区间终点，不提前5秒。前5秒仅作为波形参考，不参与是否持续达标的判断。界面/MCP/HTTP默认值已统一为7秒、50%。旧v1批次和人工记录保留，结果区可切换当前版本、旧版或历史全部；不累加不同版本的重叠事件。
