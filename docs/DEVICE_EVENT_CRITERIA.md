# 设备数据呼吸事件候选检测说明

版本 0.3.0-beta.2。适用对象为设备研发与算法复核人员。工程方案标识为 machine-flow-candidates-v2。

## 目的与适用范围

本方案利用设备 CSV 生成供人工检查的波形候选，支持起止时间、分类、时长和自动快照。公司正式判定指标尚未提供，下列工程默认参数需经公司确认和独立数据验证。成人临床参考规则只用于说明缺少什么证据，不直接用来给机器总流量贴临床标签；儿童规则不在本方案范围内。

当前文件含机器总流量、总漏气、压力、治疗压、运行状态等。未发现血氧、胸腹呼吸努力、脑电觉醒、睡眠分期或明确的气道通畅性检测通道。不能因为通道名叫流量，就认定它是已验证的患者呼吸流量；也不直接用总流量减总漏气。

## 截图指标如何处理

| 截图指标 | 成人临床参考要求 | 当前设备输出 |
| --- | --- | --- |
| 总事件时长 | 需先明确计入哪些类型，以及重叠如何处理 | 只统计两类流量形态候选区间的并集；不含漏气、缺失、信号异常；不是临床总事件时长 |
| 呼吸暂停时长 | 合适气流信号的幅度相对基线下降至少90%，持续至少10秒，结合睡眠评分语境 [1] | 输出“流量波动近消失候选”；临床暂停时长为不可判定 |
| 中枢性呼吸暂停时长 | 满足暂停条件，并根据事件期间呼吸努力判别；设备自主分类若存在也须独立验证 [1] | 当前无必要努力证据，不自动区分中枢、阻塞或混合；输出不可判定，不填0 |
| 低通气时长 | 合适气流信号幅度下降至少30%，持续至少10秒，并有至少3%血氧下降或相关觉醒；另有不同评分口径，须指定版本 [1][2] | 输出“流量波动减弱候选”；未满足完整低通气评分证据 |
| AHI | 暂停与低通气次数除以总睡眠小时数，依指定评分标准 [2] | 无可靠睡眠时长和完整事件评分，输出不可计算 |

设备波动指标与上述临床气流幅度不是同一个测量量。即使数字阈值相似，也不能当成等效评分器。

## 已实现的工程判定

1. 使用全部原始行，按源时间戳的整秒分组；不使用绘图抽稀后的点。每秒至少5个有效流量样本，否则不参与流量候选检测。该最低样本数是当前文件适配参数，不是通用采样要求。
2. 每秒波动幅度为该秒流量的95分位值减5分位值。取连续3秒的最大幅度作为包络，以减轻单秒所处呼吸相位的影响。
3. 参考基线为包络在此前120秒内的75分位值，至少30个有效秒；最低基线为3 L/min。中断或运行状态变化时重建基线。流量单位已确认L/min，最低基线为3 L/min，属于待验证的工程初始门限。
4. 波动比例为当前包络除以参考基线。它衡量机器信号的波动，不是分钟通气量、潮气量或患者实际气流。

| 工程候选 | 初始条件 | 输出边界 |
| --- | --- | --- |
| 流量波动近消失候选 | 比例不超过0.10，连续至少10秒；有效基线与质量条件满足 | 连续达标的整秒区间，左闭右开 |
| 流量波动减弱候选 | 比例不超过0.70，连续至少10秒；先移除已达持续条件的近消失区间 | 对剩余连续区间重新检查持续时间；不足时长不输出 |
| 总漏气升高 | 总漏气相对此前120秒中位基线的增量，大于10 L/min、基线绝对值的0.5倍、4倍历史绝对偏差中位值三者的最大值；持续至少10秒 | 单独输出总漏气事件，不当作非故意漏气量或临床大漏气阈值 |
| 数据缺失 | 相邻源时间戳间隔大于1秒 | 单独保留源时间间隔，不计作暂停 |
| 信号异常 | 连续至少3秒有效流量样本不足，且该段存在记录行 | 单独标记；缺失与异常段不能充当正常样本 |

严重候选优先后，两个流量类别不重叠。不足10秒的近消失波动可以作为较长减弱区间的一部分，但不会单独输出近消失事件。不跨质量排除段合并事件，不自动填补短暂恢复。

“降至基线70%”表示下降30%；旧方案默认“降至基线30%”表示下降70%。两者不能混用。界面比例设置只控制减弱阈值；近消失阈值固定为10%。最短持续时间可配置，改变后须重新评估。

## 排除条件与已知局限

总漏气升高、检测到的压力或状态突变附近不生成流量候选。压力优先使用治疗压；没有时使用压力的15秒中位滤波。相邻秒压力变化超过20Pa与30秒典型压力绝对值15%两者的最大值时，排除以该点为中心的7秒窗口；状态变化采用相同窗口。

这些条件只能降低部分混杂，不能排除所有调压、面罩移动、清醒呼吸、传感器问题或控制系统振荡。滚动基线可能随长事件逐渐下降，长期异常可能漏检；没有基线或未检出事件都不代表正常。本版尚未实现逐呼吸峰值评分、频谱振荡检测或完整形态分类。

源时间戳可能重复，文件约每秒50行不等于已核实50 Hz。检测按原始秒级时间定位；旧脚本模式仅作显示投影，不改变存储时间。PSG接入前仍需核实真实采样时序、单位、时间戳含义和不同通道延迟。

## 统计与人工复核

统计对象是最近一次设备方案扫描的原始候选，与人工确认结果分别保存。每类计数与持续时间独立列出，两类总时长取区间并集。临床暂停时长、中枢暂停时长、临床低通气时长和AHI使用空值加不可判定原因，而不是0。

旧方案事件保留，不能与新方案对同一波形的标记重复累计。自动快照保存规则版本、阈值、扫描范围、数据指纹、覆盖秒数及事件；人工确认、忽略或修订不会改写自动快照。网页扫描统计不会随人工修改重算为临床统计。

检测类型可多选或选择当前方案全检测。未选类型不输出候选，但仍计算必需的质量和混杂排除条件；未检测的流量类型与总时长使用空值并显示未检测，不能当作无事件。波形与列表的类型/状态显示筛选只影响可见性，不删除标记、不裁剪完整导出。

复核时确认正确候选、忽略误报、修正边界、补标漏检；遇到原因不明先描述形态，不强行赋予中枢等类别。只完整检查10分钟，就只声明这10分钟和实际检查的事件类型。新版精简导出支持时间范围、事件类型及逐条/完整检查方式；仍有相关待复核或未解决标记时不能声明完整。未检查部分保持未知。CSV和每批自动快照只保存一次，校验版本按内容复用；训练导入仍需合并重复及重叠校验，不能直接拼接所有JSON作为独立样本。

## 后续提供PSG的接入条件

提供同一记录对应的PSG信号与经专业人员评分的事件起止时间、事件类型、采用的评分规则和版本、睡眠分期与总睡眠时长、各信号采样率和单位、时区及设备对时方式。优先使用可导出的EDF或EDF+及事件表，保留原始文件。避免只提供总AHI数字。

先估计设备与PSG的时间偏移、时钟漂移、信号延迟及共同有效区间，再按预先固定的时间重叠或边界容差做一对一事件匹配。分别评价各类型的检出率、误报、每小时误报数和起止边界误差；仅在完整评分与有效覆盖范围内评价漏检。训练和验收按受试者或独立记录分开。

PSG数据并非导入后就自动变成可靠标签，本版尚无PSG导入和对齐模块。先完成对齐与人工抽检，再决定调整规则、训练分类器或引入设备专用模型。

## 当前设备字段确认

使用者确认压力字段单位Pa：气压1为内部，气压2为出风口，气压3为标准气压。继续仅将气压1/2减气压3，不重复扣除；其他压力字段保持当前处理。当前设备预期压力50Hz，反馈约47～48Hz，计算流量/漏气可能约30Hz但尚未核实。每秒CSV行数单独统计，不等于独立采样率。机器总流量与瞬时总漏气率均确认L/min，不是累计体积，不对所有通道强制50Hz插值。新版校验JSON的signal_metadata记录该配置；旧自动快照不追溯修改。
