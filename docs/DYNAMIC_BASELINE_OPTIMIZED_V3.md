# 动态基线优化测试 v3

网页检测方案选择“动态基线优化测试（v3 · 起点复核）”。代码 `dynamic_baseline_v3.py`，profile=`dynamic_baseline_v3`，版本=`dynamic-baseline-optimized-v3-configurable-v13`。v2保留用于对比，方法、窗口、版本及人工复核结果分别保存。

网页默认去背景绝对值均值÷2、8秒主窗口（直接调用后端未指定窗口时为5秒），检测窗口支持1～10秒整数，最短持续支持5～10秒整数；也支持去均值RMS、未去背景绝对值法。输入仍是CSV机器总流量，未做患者流量重建。因果30秒背景、此前100秒至少30个有效强度的参考，以及预候选冻结沿用v2；起始预热仍可能约一分钟，参考不足不是正常呼吸结论。

## 两类判定

- 显著下降：1秒复核强度/其冻结参考严格低于25%，连续至少所选最短持续时间（默认10秒），并有相关主窗口低于50%的佐证。保留源秒级估计边界和≤10%极低强度标记；不能直接解释为临床暂停。
- 持续减弱：所选主窗口强度/其冻结参考严格低于50%，连续至少所选最短持续时间（默认10秒）。不再要求每个1秒复核值都低于50%，所以呼吸周期内的小峰不会单独打断弱事件。
- 同一父过程有达标显著核心时优先保存核心，不重复叠加整段弱事件；恢复迟滞维持上下文，不增加不达标的事件时间。
- 弱事件先以主窗口首次达标的末端为原起点。近期节律可靠时先往前检查一个周期；找不到起点时，可扩大到一个主窗口。所有检查均限制在主窗口长度内。只有同一有效段的原始流量明确从活动波形转入持续低波动时，才采用更早的起点。持续减弱的终点可在近末段有明确流量回升并回落的形态时提前修正，修正后仍须满足最短持续。原始主窗口终点与修正量单独记录。其余情况保存连续达标窗口末端区间，不按窗口长度前移，不保证真实生理起止。确认时刻另存。末端截断后仍需达到所选最短持续时间，不越过文件终点。

显著下降起点复核使用原始流量行的顺序形态。用前12个同段源秒估计典型流量范围，寻找收敛到至少2秒稳定平台的尾段，允许第一秒出现一次有界下探后回稳；从候选前最多75个连续有效参考秒中估计近期节律，优先找5个相邻间隔，要求各自在周期中位数±25%内。最近一组至少4个一致间隔、且距触发不超过1.5个周期时可用于起止复核；较早的稳定组或只有3个一致间隔的组，距触发不超过2个周期时只用于起点回看。回看上限取半周期向上取整，限制在2～6秒；节律不清时用3秒。只在实际流量支持时剔除尾段，再检查最短持续。接近门槛且趋稳证据不足时，标记起点待复核。证据中保存原始起点与剔除秒数。修正后过短的显著核心不会用整段弱候选补回。这个规则估计机器流量何时趋稳，时间分辨率为1秒。

显著下降终点复核比较末秒与此前三秒平台。末秒流量持续偏离且下一秒同向延续时，若近期节律可靠，继续观察约1.75个周期。只有流量确实回落后再次出现同方向波动，间隔在参考周期的65%～135%，才采用较早一秒的终点，并重新核对最短持续。没有周期佐证且候选刚好达到门槛时，保留候选，显示备选终点和临界待复核提示。治疗压变化仅保留在独立的通道复核提示中。分组中位值用于形态比较，候选边界仍按原始秒轴保存。

## 排除周期内的低流量阶段

在近期可靠节律中，统计每个周期下降到低位后、再次离开低位前的时间。至少四个一致的低流量阶段才采用中位长度。两类候选均需在拟定起点附近看到最后一次高到低的实际下降，并确认流量超过典型阶段后仍低，才推迟计时。较早节律仅用于起点回看。修正后重新检查最短持续。该阶段按机器流量估计。减弱起点回看早于预触发时，按回看到的原始流量起点重新估节律，避免主窗口延迟使事件前的节律被误判过期。

## 总漏气变化仅提示复核

相邻有效源秒、同一有效段内，总漏气字段中位值变化绝对值≥10 L/min，记为工程复核提示。候选还检查此前30秒及过程内的漏气变化，保存时间、前后值、变化量，最多20处并标明截断。超过此阈值不等于已经确认“大漏气”。

漏气字段变化本身不清空强度参考、主窗口或背景，因此不会仅因漏气变化重新进入预热。持续漏气变化的短暂非事件仍不回填成已知正常背景。总漏气没有从机器流量相减。背景保留可能影响对流量偏移的解释，因此相关候选必须联合流量、压力与漏气复核。

真实数据缺失、无效源秒、模式/状态改变仍重置，不跨这些缺口拼接事件。

## 曲线、复核和导出

派生通道名称为“优化v35秒强度”“优化v35秒参考”“优化v35秒1秒复核强度”等，2/8秒对应替换窗口数字。与v2曲线独立，侧栏只默认显示当前方案需要的通道。事件详情按“1秒复核估计区间”或“主窗口连续达标区间”显示，不能把两类区间都称为每秒达标。

最短持续同时参与强/弱事件、极低强度证据、连续无效数据提示、缓存、标注来源、批次匹配和反馈范围。默认使用5秒窗口和10秒最短持续；短窗口可能更受呼吸相位影响，不同配置的重叠候选不能相加。

MCP只读分析：`analyze_recording(profile="dynamic_baseline_v3", dynamic_method="detrended_abs", window_seconds=5, min_duration=10)`；用户授权扫描保存后用同参数的`detect_events`。读曲线使用v3通道名称及匹配的`optimized_method`与`optimized_duration`。原始自动证据随人工修改保留，不重算；导出按所选批次/方法/窗口/版本隔离。未经检查的区间仍为未知。

验证包括：持续弱呼吸夹杂1秒小峰、漏气变化后的相邻事件、正常与慢呼吸、6/9秒短段、真实10秒显著下降、时间缺口、方法隔离、重复扫描、人工编辑及反馈导出。工程测试通过不代表临床准确率已验证。

## 扫描后只显示本次结果

每次扫描成功后，事件列表和图上色带按该扫描快照的事件ID筛选，包括重复扫描关联到的已存在/已复核记录。检出0条时显示为空。所有旧记录仍保留在共享存储、自动快照和备份中，不删除或覆盖。不同算法以及不同窗口、持续时间、版本不自动叠加显示。

复用已有批次也只显示该批次。需要查看以前的结果时，在“试用反馈”的扫描批次中选择后点击“显示所选批次”；动态基线的“查看本算法所有方法/窗口/持续时长”是显式历史对照入口，下一次扫描恢复仅本次显示。显示筛选不裁剪备份或替代训练反馈的人工校验范围。
