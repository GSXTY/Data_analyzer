# 动态基线优化测试 v2

网页“检测方案”选择“动态基线优化测试（新版v2）”。独立profile=`dynamic_baseline_v2`，版本=`dynamic-baseline-optimized-v2`，代码 `dynamic_baseline_v2.py`。旧动态基线v1、固定幅度规则和自适应v2/v3保持原逻辑及历史标注。

## 使用

默认“去背景绝对值均值÷2”＋5秒主窗口；也支持2秒、8秒，以及去均值RMS和未去背景绝对值法对照。点击“显示强度与基线”看曲线，点击扫描才保存候选。结果在原“动态基线检测”页签内按当前算法版本、方法、窗口区分；没有新增独立分析面板。侧栏只推荐常用源通道与当前算法派生曲线。

## 输入与背景

输入仍是L/min的CSV机器总流量。不与瞬时总漏气率直接相减，不宣称重建患者实际流量。源时间按完整秒分箱，每秒至少5个有限值、有效比例≥80%；模式/状态有记录时须有效且秒内一致。缺口/无效/模式状态变化重置全部背景、窗口与参考。

去背景法：过去30个有效源秒的原始流量样本，按每个源秒总权重相同求加权中位数作为慢背景（重复值先合并；中位落在两值间时取中点），再逐源秒计算 `mean(abs(Flow-background))/2`。直接保留原始样本分布并按源秒等权，是为减少逐秒聚合在周期波形上的相位偏差及行数变化影响；此方案仍需真实标注验证。没有可验证的1Hz滤波，也不是厂家原版算法。

参考为此前100秒内至少30个有效强度的均值，同时保留独立的1秒复核参考。去背景法通常需要背景30秒、主窗暖机及参考30秒，因此开头约一分钟不应作为正常标签。有效数据连续、仅因候选排除使有效背景历史不足30秒时，暂沿用最近有效背景，证据标明沿用及背景年龄，并逐步补足；不在每次事件后强制暖机而漏掉邻近事件。缺口、无效、状态改变或持续总漏气变化使最近背景失效时，才重新暖机并清空旧主窗/参考，避免拼接非相邻样本。

## 候选、复核和计时

1. 主窗口强度/参考或1秒复核强度/其参考首次低于50%，即冻结参考与去背景估计，缓存该过程数据。
2. 连续3秒有减弱证据形成预触发；预触发不直接保存为事件。
3. 1秒复核分箱剩余<25%严格连续≥10秒，且相关主窗口存在<50%佐证，保存“强度显著下降候选”。没有达标显著核心时，1秒分箱剩余<50%连续≥10秒且有主窗口佐证，保存“强度减弱候选”。多个达标核心分别保存，不重叠增加同一过程弱候选。
4. 连续≥10秒剩余≤10%仅作为原始证据中的“极低强度标记”，不是另一条重叠事件，也不是临床暂停判定。
5. 主窗口和1秒复核都恢复至≥60%后结束父过程；60%迟滞只维持上下文，不扩展最终达标区间。

最终start/end使用连续达标1秒源分箱的覆盖范围，精度约1秒，仍是算法估计，不是已知真实生理边界。主窗口的达标起止按窗口末端时钟另存。确认时刻满足至少10个完整分箱及主窗口佐证后才成立。没有起点减0.75W、终点减0.25W或缩短最终10秒条件。

原始自动evidence分别保留：`estimated_waveform_interval`、`main_qualified_intervals`、`main_qualified_total_seconds`、`pretrigger_confirmed_at`、`confirmed_at`、背景方法、参考及极低强度标记。多个核心可共享父过程主窗区间，不能把这些区间跨事件相加。过多主窗片段只保留前30段，并标注总数/截断；合计时长使用完整数据。

## 基线回填与质量

未形成最终事件、正常恢复且没有数据质量问题或持续总漏气中位变化≥10L/min的缓存数据，按原时间补回参考及背景历史；不会重写过去已输出的参考和判定。正常周期压力起伏只作复核提示，不阻止回填；模式/状态改变已触发质量重置。真实达标候选过程不回填。≥120秒的长段不强行截成120秒，也不自动重建成正常参考，保留完整段并提示“长段减弱/基线变化待查”。压力/治疗压20Pa、总漏气变化10L/min为复核线索，不用于调压或直接诊断。

扫描局部范围仍使用完整文件的因果上下文，保存与选区相交的完整估计区间并注明跨区。末端、缺口或状态变化截断需人工核对。

## 保存、导出及Agent

新旧profile/方法/窗口的身份与扫描匹配分开，重复扫描保护已确认/修改/忽略记录。人工改边界时，原始自动evidence和快照保持不变。反馈导出只纳入所选profile、方法、窗口、版本的自动来源标注及所选范围/类型的人工标注；未复核数据保持未知。

MCP分析/检测：`profile=dynamic_baseline_v2,dynamic_method=detrended_abs,window_seconds=5`，最终持续固定10秒。`analyze_recording`只读，`detect_events`保存候选不确认。

曲线：`get_waveform`请求“优化5秒…”通道，传 `optimized_method=detrended_abs`；旧“动态5秒…”曲线用独立`dynamic_method=centered_rms|absolute_mean`。同次读混合曲线可独立指定两个方法；每次最多8通道，显示点不能重新当分析样本。

## 验证与限制

受控分箱信号覆盖2/5/8秒主窗下的10秒下降、9秒不达标、背景偏置不变性、正弦呼吸相位、短暂下降回填、因果性、缺口/压力变化及长段提示。HTTP与MCP检查覆盖只读分析、独立快照、人工修改保护、重复扫描和反馈导出。这些是工程正确性检查，不是临床准确率；真实事件仍须完整校验区间评估精确率、召回率和边界误差，不输出OA/CA、临床低通气、正常或AHI，也不控制设备。
