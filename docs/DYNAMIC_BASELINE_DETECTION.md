# 动态基线检测（试验）

网页选择“动态基线检测（试验）”。独立方案 `dynamic_baseline`，版本 `dynamic-baseline-detector-v1`，适配器 `dynamic_baseline_detector.py`；与 `dynamic_baseline_comparison.py` / `dynamic_baseline_web.py` 共用同一计算引擎。旧设备筛查、幅度规则和自适应v2/v3保持独立。

## 使用

1. 打开CSV，在上方选择此方案，选择一种方法和一个2秒/5秒/8秒窗口（默认窗口去均值RMS、2秒）。
2. 勾选需要的类型或“全检测”，点击“扫描整份文件”或“扫描当前区间”。“显示强度与基线”只显示曲线。
3. 在“动态基线检测”页签跳转、确认、修改、忽略。默认按上方方法/窗口显示；“查看所有方法/窗口”只用于对照，重叠结果不能累计。
4. 反馈区选择对应扫描批次，填写人工检查范围、类型、人员和复核方式，经确认后导出已有反馈包。自动JSON保持原始结果；人工JSON遵循原有完整复核/抽查范围规则。未复核段不是正常标签，候选不自动变成训练真值。

网页所有算法统一从“检测方案”下拉框进入，已移除单独的只读对照面板。“显示强度与基线”按当前方法/窗口绘图；扫描后保存候选，显示或切换方案不会自动扫描。侧栏默认常用与当前算法相关通道，搜索或“显示全部通道”可找其他字段。

## 输入及处理

CSV“流量”为机器总流量，单位L/min；不直接减去总漏气，不冒充患者实际流量。按原始时间戳的源秒分箱，每秒至少5个有限值、有限比例≥80%，模式/状态有记录时须有效且秒内一致。秒内重复时间戳不按假定50Hz重建分析时钟。无效数据及模式/状态变化重置窗口、参考；不跨缺口桥接。

- `absolute_mean`：逐秒计算 `mean(abs(Flow))/2`，再对相邻2、5或8个完整源秒求平均。保留机器流量背景，背景可掩盖呼吸减弱。
- `centered_rms`：相邻2、5或8个完整源秒的均值与二阶矩计算窗口去均值RMS，按源秒等权；只表示机器波动强度。不是经过校准的患者流量RMS。

未实现可验证的1Hz滤波，不是ResMed完整实现。两种方法必须人工对照验证，候选数量不代表准确率。

## 参考与判定

参考B为此前100秒内有效、未被冻结的强度均值，至少30个有效参考秒。首次剩余比例 `<50%` 即冻结参考，不等10秒确认；恢复到 `≥50%` 关闭过程并恢复参考更新。

- 显著下降：强度/B `<25%` 严格连续达到10秒。存在达标核心时只保存核心，不再叠加同一过程的弱候选。
- 减弱：没有上述达标核心，但整个 `<50%` 过程严格连续达到10秒。
- 计时从首次达标的窗口末端开始，确认时刻为起点+10秒，不把前2/5/8秒窗口补进持续时间。固定10秒与其他方案的7秒独立；当前API拒绝其他持续设置。
- 扫描选区使用完整文件参考上下文，保留与选区相交候选的完整边界并提示跨区。记录末尾/无效数据截断会保留提示，需人工检查。
- 原始时间戳间隔另标“数据缺失”，不意味着已证明每一秒均丢失样本；源秒有效性不达标连续≥10秒标“信号异常”。这些不是呼吸事件。

压力/治疗压变化20Pa、总漏气变化10L/min仅作为复核提示，不据此删除候选，不执行调压。所有类别是工程候选；没有呼吸努力、血氧、脑电及患者流量验证，不输出临床暂停、低通气、OA/CA、正常或AHI。

## 保存与Agent

方法、窗口、版本参与事件身份和扫描批次匹配；不同配置不会按重叠自动合并。相同配置重扫按原始事件ID去重，保护人工修改、确认、忽略状态。人工修改后的原始自动证据不会重算；自动JSON快照保持扫描当时结果。

此方案导出人工反馈时，自动来源只取所选批次的同方法、窗口和版本；其他配置的候选不混入、不阻碍本配置完整复核。范围内所选类型的人工/Agent标注仍按原规则保留。相同包重复导出复用原CSV和JSON，不额外复制。

MCP `analyze_recording(..., profile='dynamic_baseline', dynamic_method='centered_rms', window_seconds=2)` 只读；`detect_events` 使用同样参数保存待复核候选。`get_waveform(dynamic_method='centered_rms')` 获取相同方法的动态强度、参考、门限、比例曲线。更新后需要重启查看器；旧MCP连接若缺参数需重新连接，不能用显示降采样点重新检测。

新增5秒窗口与2秒、8秒使用同一逻辑，固定连续10秒规则不变。后台研发只读接口保留单5秒及原both=2/8对照语义；网页只从统一检测入口选择窗口。窗口信息保存在事件、判定证据、自动快照及人工JSON中。
