# 多特征自适应测试 v3

独立方案 `adaptive_multifeature`，版本 `adaptive-flow-test-v3-multifeature`，实现于 `multifeature_test.py`。网页选择“多特征自适应测试（新版）”。原 `adaptive_test` / v2、固定幅度规则和设备候选保持原行为、历史及人工标注。

## 输入与窗口

使用CSV原始机器总流量（L/min），不与瞬时总漏气率相减。原始时间戳按源秒分箱，每秒至少5个有限流量值且有限比例≥80%；模式/状态有记录时须有效且秒内一致。相邻5个完整有效源秒的高98%分位最大值减低2%分位最小值为A，每秒末端更新。缺口、无效数据、模式/状态变化会重置窗口及参考；治疗压力变化不直接删除候选，作为复核提示。

参考B为此前120秒内至少30个有效、非减弱过程A的75分位，减弱过程内冻结。全部仅用当前及此前数据，不读取未来，也不将秒内重复时间戳强行按50Hz展开后检测。

## 严格比例、7秒及边界

- 近消失：A/B≤0.10且噪声代理检查允许分型，连续达到7秒（持续可调）。
- 减弱：A/B≤所选剩余比例（默认0.50），连续达到7秒。若同一减弱过程含合格近消失核心，只输出核心，不把外围减弱肩部重复计为第二种事件。
- 两条幅度门限分别为0.1B和0.5B，没有3 L/min绝对下限。比例比较是机器波动幅度，不能称为已验证患者气流下降。
- 减弱退出比例默认0.60（随输入比例计算且高于进入）。迟滞只冻结整体过程参考；每条输出区间仍需严格连续达标，不把迟滞区或分散的几段短时长相加。
- 事件区间为首次合格评价时刻至首次不合格评价时刻的半开区间；确认时刻=起点+最短持续。先前5秒不加到起点或时长。因5秒因果窗口仍有检测延迟，所报起点不称为真实生理起点。
- 原始数据中断、模式变化和记录末端会截断，并保留标志。中断不补造达标秒数。使用整份记录上下文，选区扫描返回与选区相交的完整事件。

## 噪声及辅助特征的限制

每源秒以相邻原始行流量二阶差分绝对值中位数×2作为粗糙度/噪声代理；不足10个有限值时不提供此代理。它受量化、重复值、通道更新方式及真实波形影响，并非校准噪声或物理噪声标准差。0不代表无噪声。

此前参考噪声代理75分位及当前代理用于保守检查：B须大于参考代理3倍才可分析；0.1B须大于参考及当前代理较大值3倍才允许近消失分型。否则保留符合比例的减弱候选及“分辨率不足”提示，不提高近消失门限。代理不充分时也不判近消失。所有系数为可验证的工程假设，不能声称解决了硬件噪声标定。

记录源秒中位序列的转折数和粗周期提示、平直秒数、孤立尖峰/流量突跳、此前30秒与区间内压力/总漏气中位变化。压力20Pa或总漏气率10 L/min仅为复核提示。持续平直不能直接区分真实低波动与信号冻结。没有已验证采样时钟时不计算精细吸气时间、潮气量、真实呼吸次数，不将粗转折当成呼吸努力。

暂未新增吸气扁平化分类、FOT/压力脉冲分类，也未实现训练模型。不能从普通CSV模拟补出未采集的气道通畅性响应。无呼吸努力、血氧、脑电与验证标准，不输出临床暂停、OA/CA、临床低通气、正常或AHI；无候选不代表正常。

## 图表、依据和反馈

点击“显示输入与A”将A、B、近消失/减弱门限、噪声代理放在同一数值轴，剩余/下降百分比另图。门限和参考按当前持续时间/剩余比例计算，参数加入缓存键；跳转新版事件时恢复其参数。图表抽取点仅供显示，检测始终读取完整原始行。

事件保留 `detection_profile`、`detection_version`、`detection_input` 及结构化 `evidence`（原始自动依据、参考/幅度、最大/中位比例、确认时刻、严格时长、压力漏气变化、质量提示）。人工修改类型、边界、备注时保留原始自动依据供溯源；依据不代表人工重新计算的结果。自动快照不可变，重复同参数扫描只按相同ID去重，人工状态不被覆盖。新旧版本在结果版本筛选和批次中分开，不累加重叠候选。

MCP：`analyze_recording(profile="adaptive_multifeature")` 为只读；明确授权后 `detect_events(profile="adaptive_multifeature", min_duration=7, reduction_ratio=.5)` 保存候选。`get_waveform` 新增 `test_duration` / `test_ratio`，查看派生参考线时与扫描一致。升级后重启查看器并重新连接MCP。

## 公开机制来源及验证

借鉴逐次呼吸、波形形态和干扰处理的思路，未声称复现厂商内部实现，参数不是厂商统一标准：

- [ResMed AirSense 10 Plus临床说明书](https://ap.resmed.com/hubfs/1%20Official%20-%20B2B%20Product%20Marketing%20Collateral/Marketing%20Materials/AirSense/AirSense10_ClinicalGuide_EN.pdf?hsLang=ta)：逐次呼吸、流量受限及FOT机制。
- [Philips DreamStation BiPAP S/T/AVAPS说明书](https://www.documents.philips.com/assets/Instruction%20for%20Use/20250630/6549a539317e4d15b8efb30c01114621.pdf)：相对下降/持续时间、压力测试脉冲和大漏气影响。

测试覆盖严格90%边界、旧3 L/min错误放宽、连续6/7秒、不累计跨阈值间隔、噪声不足、缺口截断、压力/漏气共变、因果图表、参数缓存、标注溯源及MCP往返。已有三份CSV仅用于只读回放，结果变化不等于准确率提高。下一步应固定参数，用独立记录及人工明确完整复核的区间比较漏检、误报、边界误差和可分析覆盖率；未经检查的区间不作为负例。
