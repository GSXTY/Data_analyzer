# 公司压力推算流量规则（试验）

## 输入选择更新

在同一个“幅度规则（试验）”方案中，可选择“CSV流量”（网页默认）或“压力估算Q”。CSV流量直接读取原列，不经过压力多项式；新增“流量波动幅度A（5秒极差）”通道与检测共用计算。点击“显示输入与A”查看所选输入及A。两路输入分别显示候选、保存批次和去重；旧压力估算结果保留，切回该输入可查看。

CSV输入版本为csv-flow-amplitude-v1，参数记录flow_source=csv_flow，事件记录detection_input。压力估算保留旧版本和既有设置。MCP调用需明确传flow_source=csv_flow；未传时为兼容旧客户端仍使用pressure_q。5秒窗口、每秒末端评价、连续严格超过7秒及10/17边界均未改变。不同输入可能产生不同候选边界，需结合原始记录复核；候选区间不等于已验证设备事件的真实起止。

来源是使用者提供的算法截图，无设备源代码。P1/P2分别减气压3已由使用者确认；Q暂按L/min试用，与CSV流量是否同一公式、压力校准范围仍待研发确认。

```text
Q = -8.26876272861618
    +0.830695671071454 P1 -0.831894817072964 P2
    -0.0000423257870468439 P1² +0.0000406935371268139 P2²
    -0.000625461373311312 (P1-P2)²
P1=气压1-气压3，P2=气压2-气压3，单位Pa。
```

网页选择“公司规则（试验）”。自动提供“公司公式Q（试验）”通道，原CSV流量保留。默认持续门限7秒；“超过”是严格大于。70%参数仅属于原相对幅度方案，在本方案隐藏且不参与计算。

点击“显示公司Q和A”可不经扫描直接查看“公司A（5秒极差）”。A使用与检测器相同的完整原始数据计算，每秒末端更新并保持到下次更新；前5秒或含无效秒的窗口留空。A图有10/17参考线，鼠标悬停显示数值。旧脚本时间展开只用于显示，不重新计算A。

下方结果分为“自动检测”“公司规则”“人工 / Agent”三个独立页签；列表、波形事件标记和类型/状态筛选随页签切换。公司质量事件也留在公司页。新事件持久保存detection_profile，人工修改类型/备注后仍保留来源；旧事件按原类型/规则备注识别。JSON备份和CSV导出保留全部结果，不因显示页签裁剪。

暂定：每秒末端评价之前5个完整源时间秒的Q最大值−最小值A。A<10为公司暂停候选；10<A<17为公司低通气候选；等于10/17均不归类。每秒至少5个有限Q值才视为有效，不补点或强制50Hz。缺失/无效秒使5秒窗口重新积累。原始极值对尖峰敏感，先不额外平滑。压力/漏气/状态需人工联合复核，本方案未继承原方案的干扰排除。

计时记录条件成立的窗口末端时刻；例如首次在第5秒满足，末次在第12秒满足，跨度7秒，不满足“超过7秒”；到第13秒仍满足时跨度8秒，可生成5—13秒候选。起点不是第0秒的波形开始，也不是达到持续门限后的报警触发时刻。该口径尚待研发确认，不宣称亚秒精度。

阈值、系数、补偿方式、计时假设随扫描批次保存。不同方案分批统计，不合并为临床事件总数。试验结果均待复核，不自动确认、不区分OA/CA、不计算AHI。截图的升压/调压动作不执行。
